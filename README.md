**Sébastien Beyh, PhD**

## About the Book

*AI-RAN Engineering* explores the engineering principles, architectures and technology considerations surrounding the integration of artificial intelligence into radio access networks and future 5G/6G systems.

The work addresses the intersection of:

- Artificial intelligence
- Radio access networks
- 5G and 6G
- Network intelligence
- Automation
- Network optimization
- Edge computing
- Intelligent infrastructure
